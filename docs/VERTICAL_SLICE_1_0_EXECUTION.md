# Everdune — Hearthfall Vertical Slice 1.0

Status: ACTIVE BUILD

Single playable path:
Boot → Title → Creator → Hearthfall → Mara → Gather → Fish → Old Road Echo → Mara return → Glass Orchard Echo → Craft → Sleeping Gate → Combat → Home.

Implementation order is locked:
CI/web contract → real TileMap world → real collision → final hero → Mara → first Echo → gathering/fishing/crafting feel → Sleeping Gate → combat → audio → first-run QA.

The companion website is a window into the exported Godot slice; it must not invent a parallel game implementation.

## Engineering rule

No new breadth while a player-facing gate remains unfinished. Replace prototype presentation with authored runtime content and keep temporary implementations in the placeholder registry until they pass review.

## Completion evidence

- Browser export and website integration pass in CI.
- Hearthfall geography is represented by TileMapLayer/content data, not a scene image acting as the map.
- Player collision comes from physics/world geometry rather than hardcoded river coordinates.
- Hero, Mara, Echo, gathering/fishing/crafting, Sleeping Gate, combat and audio have deterministic regression coverage where practical.
- `/play/` embeds the same Godot build generated by the web build.


## Implemented in the current build

- Hearthfall is now a multi-layer TileMapLayer runtime: Ground, River and PathsAndBridges.
- River water carries TileSet physics collision; player movement contains no river-specific collision rules.
- World boundaries and landmark footprints are owned by the Hearthfall world.
- The hero uses a complete runtime layer stack: back item, boots, trousers, shirt, body, face, coat, hair, accessory and tool.
- Mara has a runtime routine, authored identity treatment, relationship progression and post-Echo response.
- The Old Road Echo changes world presentation and progression rather than only awarding a reward.
- Gathering has contact animation; fishing now has cast → bite → reel timing; crafting changes the home presentation.
- Sleeping Gate has a three-enemy encounter with variants, telegraphs, hit-stun, health bars and a completion state.
- Slice audio is built around authored musical motifs for the player-facing events.
- Clean-save regression coverage now checks initial state, TileMap topology/physics, Echo progression, hero assets and save migration.
- The companion website hero now embeds the exported Godot build directly, making the public site a real window into the game.
