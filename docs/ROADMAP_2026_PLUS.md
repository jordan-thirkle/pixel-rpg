# Everdune Long-Term Roadmap

Status: LOCKED DIRECTION — 2026-09-28

## Stage 0 — Architecture freeze

The Godot 4.7.2 + TileMapLayer + data-driven architecture is now frozen.

Do not introduce another gameplay framework to solve a content problem.

Changes to architecture require a demonstrated failure in the existing model and a regression test proving the replacement.

## Stage 1 — Free-play foundation

Goal: make a 45-minute self-directed evening genuinely possible in Larkmere.

Build deeply:
- woodcutting;
- mining;
- foraging;
- fishing;
- farming;
- cooking;
- crafting;
- building;
- wayfinding;
- decorating;
- optional combat.

Each skill must have a reason to exist beyond XP.

## Stage 2 — Systemic consequence

Goal: make player actions accumulate.

Build:
- world memory;
- persistent routes;
- restoration;
- NPC reactions;
- home changes;
- collection displays;
- activity statistics;
- contextual dialogue;
- weather/time interactions;
- seasonal state.

The test is: "Can I point to something in the world and know that I caused it?"

## Stage 3 — NPC lives

Goal: people should appear to have lives even when the player is not doing quests.

Build:
- daily routines;
- work/home/favourite places;
- relationships;
- personal goals;
- memories;
- contextual dialogue;
- weather reactions;
- world-change reactions;
- invitations and visits;
- small personal stories.

## Stage 4 — Systemic Echoes

Goal: Echoes become the signature Everdune system.

Build:
- place/object/person/creature/event/environment Echo types;
- evidence presentation;
- multi-step Echo chains;
- knowledge tags;
- world consequences;
- NPC memory reactions;
- activity unlocks;
- restoration chains;
- Echo collections without checklist pressure.

## Stage 5 — Personal home

Goal: the home becomes a readable autobiography.

Build:
- rooms;
- furniture;
- storage;
- functional stations;
- trophies;
- maps;
- books;
- Echo artefacts;
- gardens;
- NPC visits;
- visible history.

## Stage 6 — Dense Larkmere

Goal: one valley can support dozens of evenings.

Every location gets:
- activities;
- resources;
- people;
- secrets;
- stories;
- Echoes;
- restorations;
- reasons to return.

No second region until this standard is demonstrated.

## Stage 7 — Mastery and replayability

Build:
- collections;
- rare discoveries;
- optional dungeons;
- Gauntlet;
- challenge mastery;
- build choices;
- equipment identity;
- controlled RNG;
- seasonal events;
- world events;
- long-tail achievements.

## Stage 8 — Expansion

Only after Larkmere is genuinely deep:
- second region;
- new world rules;
- new skills where justified;
- new factions;
- new Echo families;
- new NPC communities;
- new restoration chains.

Expansion must compound the existing simulation rather than replace it.

## Stage 9 — Commercial platform

After the core game is excellent:
- Steam integration;
- achievements;
- cloud saves;
- controller/gamepad;
- key rebinding;
- accessibility;
- localization;
- telemetry only where useful and privacy-respecting;
- co-op transport boundary.

## Stage 10 — Long life

The game should eventually support:
- player-driven projects;
- seasonal world changes;
- rare memories;
- deep collections;
- community restoration;
- optional mastery;
- additional regions;
- new Echo chains.

The game ends when the player decides their current life is complete, not because every player must reach the same checklist.

## The brutal product gate

Before expanding breadth, ask:

**Can I launch after a stressful day, ignore the story, choose one simple activity, and naturally find several meaningful things to do without being forced?**

If not, build depth.
