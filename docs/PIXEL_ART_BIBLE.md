# PIXEL ART VISUAL BIBLE

## Style

**Cinematic Pixel Fantasy**

High-detail pixel art combined with modern presentation:
- crisp nearest-neighbour rendering
- deliberate palettes
- strong silhouettes
- expressive characters
- atmospheric lighting
- dynamic weather
- layered depth
- readable UI
- restrained magical effects

## World palette

Deep forest greens, river blues, warm timber, parchment cream, sunset amber, restrained flower colours and cool moonlit blues.

Magic may introduce rare accent colours but should remain visually scarce.

## Characters

Characters use a layered visual system:
- base
- hair
- face
- shirt
- outerwear
- trousers
- boots
- accessory
- weapon/tool
- back item

Equipment must fit the same character proportions and pixel grid.

## Environments

Playable space must remain readable beneath detail.

Use distinct foreground, gameplay and distant layers.

Landmarks should be authored, not random clutter.

## Lighting

- day/night palette shifts
- warm local lights
- fire and lantern glow
- rain/fog
- water reflections
- pixel-aware shadowing

## UI

Fantasy material language using wood, parchment, iron and brass.

Avoid generic neon MMO panels.

## Asset acceptance

An asset enters the canonical library only when it passes:
- grid consistency
- palette consistency
- silhouette/readability
- scale
- pivot/alignment
- animation-frame consistency
- semantic naming
- world/style fit
