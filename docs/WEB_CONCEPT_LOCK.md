# Everdune Web Concept Lock

The supplied Everdune website image is the canonical composition reference for the public-facing website.

## Layout lock

1. Persistent left identity rail with Everdune mark, subtitle, section navigation, atmospheric landscape art, and Steam CTA.
2. Thin global top navigation across the main content.
3. Large central gameplay viewport presented as the visual hero.
4. Right-side parchment lore book with vertical chapter tabs.
5. Four illustrated feature cards directly below the hero.
6. Deep navy / ink page background, antique parchment, timber, iron and brass framing.
7. Dense cinematic pixel-fantasy imagery with warm lantern light, teal river water, forest greens and restrained rose blossom accents.

## Product rule

The concept is a composition reference, not a request to turn the website into one flattened image. All navigation, buttons, lore tabs and game preview controls remain real HTML elements.

The playable game remains the Godot runtime. The website owns presentation, discovery, lore and the browser-play shell.

## Review

The earlier minimal web page was structurally correct but visually far below the approved concept. This lock moves the implementation toward the actual composition: fixed rail + top nav + game frame + parchment lore book + feature strip, with responsive collapse only where needed.

The current game is still a development vertical slice. Its art should continue moving toward the same cinematic pixel-fantasy language without using the marketing mockup as a literal runtime screenshot.
